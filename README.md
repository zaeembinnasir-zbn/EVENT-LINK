EventLink

Connecting Devices. Coordinating Events.

1. What Is EventLink?

EventLink is a cross-platform event-management and communication project designed to connect Windows PCs and Android devices over a local network. It aims to simplify the coordination of school events, competitions, workshops, and large gatherings through a unified platform.

Key Features

Attendance Management: Organize attendance records and export them to Excel, where supported.

Device Connectivity: Connect supported Windows and Android devices over a local network.

Communication: Chat, push-to-talk, and file sharing, where implemented.

Alerts: Support event notifications and emergency status broadcasts.

Windows Utilities: Installation scripts, launch tools, and setup documentation.

EventLink aims to bring essential event-management tools together, reducing reliance on separate applications and making event coordination more efficient. Feature availability depends on the current build.

2. How to Download and Install

Step 1 — Download: Open the EventLink GitHub repository, click Code, and select Download ZIP.

Step 2 — Extract: Open your Downloads folder, right-click the ZIP file, select Extract All, and open the extracted folder.

Step 3 — Install on Windows: Go to Eventlink_Local_App Run allow_firewall.bat as Administrator and then run_eventlink.bat as Administrator, if included, and follow the displayed instructions.

Step 5 — Android: Download a compatible APK from the repository's Releases section if available. If only source files are provided, follow the Android build instructions.

Step 6 — Connect Devices: If supported, connect both devices to the same trusted Wi-Fi network and follow the application's connection instructions.

Troubleshooting: If the application fails to start or devices cannot connect, check the terminal errors, dependencies, network configuration, and firewall rules.

Security: Download files from a trusted source, inspect scripts before running them, and never publish passwords or API keys.
