EVENTLINK LOCAL

1. On Windows 10/11, install Python 3.10+ if needed.
2. Double-click run_eventlink.bat.
3. The window prints the six-digit event code, host token, and local URL.
4. If another device cannot connect, run allow_firewall.bat as Administrator.
5. Connect Android/Windows devices to the same LAN and open the printed local URL.
6. Join with name + code. Host/Admin opens the Host control and enters the host token.

Internet may be available, but is not required for the local event path.
No OpenAI API key is required for the local server.

This is the first working LAN build: join/approval, cross-platform chat, rooms, Poke, Code Green/Red/Black, attendance database, CSV export, host controls.
Native APK/EXE wrappers are included as build notes; this environment does not honestly compile/sign platform binaries.
