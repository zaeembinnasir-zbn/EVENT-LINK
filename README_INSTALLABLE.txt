EVENTLINK LOCAL — INSTALLABLE PACKAGE
=====================================

This package gives you:
- One-click Windows installer script.
- Installed local server under %LOCALAPPDATA%\EventLinkLocal.
- PWA install support for Android and Windows.
- Dedicated local LAN operation.
- No OpenAI API key required for local communication.

IMPORTANT:
A true native .exe and .apk cannot be compiled inside this environment because the
Windows native toolchain and Android SDK are not available here. I am not labeling
the PWA or batch launcher as a compiled native APK/EXE. The source/config needed
for those native builds is retained in the package.
